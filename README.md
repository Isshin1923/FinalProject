# BookShelf — Каталог книг та рецензій

Вебсайт із кураторською добіркою популярних книг, їхніми обкладинками, описами, жанрами та оцінками.

## Функціонал та сторінки

- **Головна сторінка (`index.html`)** — презентаційний банер, добірка «Вибір редакції» з обкладинками книг та огляд популярних літературних жанрів.
- **Каталог книг (`pages/catalog.html`)** — розширена бібліотека рекомендованих творів (фантастика, класика, фентезі, детективи, нон-фікшн) із рейтингами та роками видання.
- **Про проєкт (`pages/about.html`)** — інформація про ідею створення сайту.
